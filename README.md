# AGenNext UI Tool Kit

Reusable UI toolkit for agentic, AI-native, and product interfaces.

Inspired by:

- A2UI-style action-oriented agent interfaces
- CopilotKit-style embedded copilots and AI interaction surfaces
- Reusable SaaS/admin/dashboard component systems

## Use cases

- AI applications
- Agent dashboards
- SaaS products
- Admin panels
- Workflow systems
- Research interfaces
- Copilot experiences
- Human-in-the-loop review tools
- Execution trace viewers
- Agent orchestration screens

## Stack

- React
- TypeScript
- Vite
- Lucide Icons

## Toolkit areas

- Design tokens
- Layout primitives
- Cards and panels
- Buttons and badges
- Agent status components
- Action surfaces
- Copilot/chat shells
- Timeline and trace UI
- Dashboard widgets
- Workflow/canvas building blocks

## Development

```bash
npm install
npm run dev
```

## Build

npm run build
